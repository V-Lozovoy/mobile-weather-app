# Weather - SP5

Локальна база: SQLite, Drizzle, міграції, live-запити - тільки читання.
React Native + **Expo SDK 57**, TypeScript, drizzle-orm, expo-sqlite.
**Цей файл і є завдання** - специфікація, критерії та бали нижче.

Заготовка працює і навіть тримає базу: `src/db/client.ts` відкриває weather.db
(зі слухачем змін - чому, написано там), розсів восьми міст готовий. Але схеми
нема (дві колонки замість таблиць), міграцій нема (теча `drizzle/` порожня),
і стрічка досі читає стор із пам'яті. Остання робота курсу - і
перший «перезапустив - усе на місці».

## «Зроблено» виглядає так

Стрічка вісімох міст із температурами - і та сама після перезапуску. Літак,
вбив застосунок, відкрив - міста й градуси на місці, жодного запиту в мережу.

Прочерк замість градусів означає, що кеш порожній: місто в базі є, прогнозу
для нього ще немає. До TODO(4) прочерки стоять у всіх восьми - так і має
бути.
