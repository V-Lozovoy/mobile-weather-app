без погоди. Це стартова позиція, а не зламане завантаження. Ваша робота — два `TODO`,

## Як запустити

Потрібні **Node.js LTS** на ноутбуці та **Expo Go** на телефоні (App Store / Google Play).

```bash
npm install
npx expo start          # QR-код у терміналі
```

Відкрийте камеру (iOS) або застосунок Expo Go (Android) і відскануйте QR-код — застосунок
запуститься на телефоні. Ноутбук і телефон у різних Wi-Fi мережах: `npx expo start --tunnel`.

## «Чого тут немає»

- **Жодного `FlatList` і `.map()` по містах.** Списки — це S2 і робота SP2; сьогодні
  екран показує одне місто.
- **Жодної навігації, другого екрана й `expo-router`.** Це теж SP2, поверх екрана,
  який уже працює. Сьогодні не додавайте.
- **Жодної мережі.** Дані написані руками в `src/data/mocks.ts`, тож пара переживе
  мертвий аудиторний Wi-Fi. Справжнє API приїде в SP3.
